Savorly is a recipe finder web app I built to make it easier to look for recipes based on the ingredients you have.

- View recipe details and instructions

- Responsive layout for different screen sizes
- Loading and error states

Built with ୭˚. ᵎᵎ
- HTML
- CSS
- JavaScript

How it works?? 
You can search for an ingredient, and Savorly gets matching recipes from TheMealDB API. 
From the search results, you can open a recipe to see its ingredients and instructions. You can also save recipes that you want to come back to later.
